# Security Policy

## Reporting a Vulnerability

Please do not open a public GitHub issue for suspected security vulnerabilities.
Email `team@noisefactor.io` with:

- the affected Seance version or commit,
- a description of the issue and potential impact,
- reproduction steps or proof-of-concept details, and
- any relevant logs, traces, or client/runtime information.

We will acknowledge reports as quickly as possible and coordinate fixes before
public disclosure. Please give us a reasonable window to investigate and ship a
patch before sharing details publicly.

## Supported Versions

Security fixes are made against the current `0.2.x` release and the `main`
branch until a formal release support policy is published.
